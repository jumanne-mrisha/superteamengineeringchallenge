# Inventory System

This is an Inventory Management System built with Laravel for backend and Bootstrap for frontend. It allows users to manage products, record sales, and track inventory in a simple and efficient way.

## Features

- **Dashboard**: View the recent sales and statistics.
- **Sales Management**: Record and view sales, including product, quantity, and amount.
- **Inventory Management**: Track product stock and update inventory after sales.
- **Export Sales Data**: Export sales data as a CSV file.
- **User Authentication**: Secure login and session management.
  
## Requirements

- PHP >= 7.4
- Laravel >= 8.x
- MySQL (or other compatible database)
- Composer
